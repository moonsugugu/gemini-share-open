제미나이 캔버스 공유 링크가 하얀 화면으로만 뜨나요? 2026년 11월 2일 제미나이 업데이트 뒤로 생긴 구글 쪽 오류예요. 앱이나 계정 설정 문제가 아니에요. 아래 노란 버튼을 북마크바에 한 번만 넣어 두면, 백지 화면에서 눌러서 바로 열 수 있어요.

1

북마크바를 켜 주세요

주소창 바로 아래에 북마크 줄이 안 보이면 Ctrl + Shift + B 를 누르세요. 맥은 ⌘ + Shift + B 예요.

2

노란 버튼을 북마크바로 끌어다 놓으세요

버튼을 마우스로 꾹 누른 채 위쪽 북마크 줄까지 끌고 가서 놓으면 끝이에요. 처음 한 번만 하면 돼요.

3

하얀 화면에서 북마크를 누르세요

공유 링크를 열었는데 하얗게만 나오면, 북마크바의 제미나이 캔바스 앱 공유 오류 해결을 한 번 누르세요. 2~10초쯤 지나면 앱이 나타나요. 큰 앱은 조금 더 걸려요.

다른 사이트로 옮기는 게 아니라, 원래 제미나이 공유 페이지 안에서 그대로 열려요.

끌어다 놓기가 안 되나요? 직접 등록하기
  1. 아래 코드 복사를 누르세요.
  2. 북마크바 빈 곳에서 오른쪽 클릭 → 페이지 추가(엣지는 즐겨찾기 추가)를 고르세요.
  3. 이름에 제미나이 캔바스 앱 공유 오류 해결, URL 칸에 복사한 코드를 붙여넣고 저장하세요.

휴대폰에서도 되나요?

아니요. PC의 크롬, 엣지, 웨일에서 써 주세요.

이 버튼이 무슨 일을 하나요?

제미나이 화면이 받아 온 앱 데이터를 엉뚱한 이름으로 찾고 있어서 하얗게 나와요. 버튼은 그 이름만 맞춰 줘요. 어떤 정보도 다른 곳으로 보내지 않아요.

구글이 고치면요?

그때는 버튼 없이도 그냥 열려요. 눌러도 아무 일이 생기지 않으니 지워도 되고 그냥 둬도 돼요.
